# 01 选题与研究问题

> 模板见 `../assets/templates/选题.md`；自检见 `../cheatsheet.md`。

## 这一节要干什么
在动笔前先回答两个根本问题：**写什么（主题）** 与 **回答什么（研究问题）**。彭玉生："问题是一项研究的灵魂"；张静："好问题是好研究的开始。"问题先于假设——文章应起始于研究问题，而非研究假设。

## 步骤（手把手）
1. **找源头**：从三条路出发——① 文献阅读中发现的未知；② 未解决的现实问题；③ 有趣的现象/反常。
2. **列出候选主题**，用"好问题四标准"（彭玉生）逐条自检：
   - **具体**：明确不空泛，"以小见大"远胜"虎头蛇尾"；纯实证要"看料下锅"，问题与手中资料匹配。
   - **集中**：专注一个或围绕同一理论轴心的若干问题；写论文≠写书，多问题须围绕同一理论轴心。
   - **原创性**：新现象≠创新；真正创新多在老话题用崭新视角/理论框架；稳妥做法：围绕当前学术前沿争论提问。
   - **意义**：符合逻辑与事实（先排除"假问题"）；更强调**理论缘由（theoretical rationale）**——每个好经验问题背后都有理论问题。
3. **把个人兴趣转译为研究问题（research query）**（Machi Step 1）：聚焦 → 限定 → 选视角 → 反思，写成"初步研究主题陈述"。
4. **区分经验问题三类**：描述性 / 解释性（explanatory）/ 意释性（interpretative）。
5. **张静式操作**：选"小题目"小题大做；从私人叙事抽象出**公共含义**（用关键词统计看谈论最多的话题、让受访者自评标准再归类）；提问三型：事实性 → 解释性 → 预测性。
6. **形成可回答、可证伪的研究问题句**：一句话能说清"我想回答的中心问题是什么"。

## 反模式（常见坑）
- 题目过大、过抽象，换到任一篇都可用。
- 用**个人动机/政治重要性/道德关怀**当"理论缘由"（彭：这些不能算理论缘由）。
- "假问题"——前提违背事实或逻辑（如把"劳力过剩"当成因）。
- 把**问题域**（"研究国家与社会的关系"）当成**具体问题**（须分解为可用问号的具体问题）。
- 由他人出题但不理解，导致跑题。

## 自检清单
- [ ] 我能否用一句话说出中心研究问题？
- [ ] 它具体、集中、有理论缘由吗？
- [ ] 它是描述/解释/意释中的哪一类？
- [ ] 我的资料/理论能支撑回答它吗？
- [ ] 它是否踩在学术前沿争论上（原创性的稳妥来源）？

## 增补：Edwards「把念头压成研究问题」的心智动作
- **人 ⇄ 组织**：从"谁偷书"转为"什么样的图书馆更能减少偷书"；从"哪个女生更会卖饼干"转为"哪些女童军组织更会卖"。
- **个体 ⇄ 聚合**：从"哪些低收入者会申请救助"转为"哪些州的申请率更高、为何"。
- **熟悉却理解不足**：从"人人都见过、却说不清"的现象切入（"这很常见，但我们知道得很少"）。
- 灵感多来自问题/经历/争论，而非只从文献缺口里找（Edwards 提醒：别迷信"读文献找洞"）。
