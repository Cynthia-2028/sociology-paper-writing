# 08 结论与讨论

> 模板见 `../templates/结论与讨论.md`。

## 这一节要干什么
彭玉生给结论三项任务：① 概括经验发现（验证/证伪了什么假设、回答了中心问题）；② **探讨证实/证伪的理论含义**（最重要）；③（若愿意）做进一步理论推论（新假设）。张静补充：用专业概念对证据说明的问题定性定位，扣住前面提出的问题，回应文献、评估局限，参照理论框架总结意义。

## 步骤（手把手）
1. **总结发现**：最初什么问题？用什么结论回答？目标是否达到？发现/证明了什么？
2. **理论含义**（核心）：针对前文文献/理论综述阐明经验发现的含义——这是结论最该写重的部分。
3. **比较与一般化**（张静两大基本功）：
   - 概述共性、比较差异——研究必在一系列比较中进行（前人经验/不同解释范式/资料/历史现今/原因后果/机制……）。
   - 一般化——把结论合乎逻辑地上升联系到领域重大问题，或用更高抽象层级概念概述（未证明则勿强行概括）。
4. **讨论（开放）**：结论含义、理论/政策价值、相关问题、潜在影响、贡献、**局限**、改进方向。
5. **诚实写局限与边界**：尤其定性研究的"发现"严格说是新假设，要写明推论边界。

## 反模式
- 总结无结论或轻描淡写；把结论陈述当成价值评估（论述为何正确、为何好）。
- 在结论大篇幅讨论前文根本未涉及的新文献/理论（应整合进文献综述）。
- 只谈贡献不谈局限，显得不诚实。
- 强行一般化到未证明的宏大命题。

## 自检清单
- [ ] 是否概括了经验发现并回应了中心问题？
- [ ] 是否写清了发现的**理论含义**（而不仅是重复结果）？
- [ ] 是否做了比较/一般化，且未强行越界？
- [ ] 是否诚实说明了局限与边界？
- [ ] 是否避免了引入前文未出现的新文献/理论？

## 结论的写法（Edwards / Martín）
- **Edwards**：结论"简洁但完整"——只读结论也应知道：回答什么问题、主要发现、最终意味着什么；重述与理论意涵必须清楚。
- **Martín（IBC 结构）**：叙事型文章 Introduction ≈15%、Conclusion ≤10%，主体占其余（可用于控制篇幅比例）。
