# 07 实证分析

> 模板见 `../assets/templates/实证分析.md`。

## 这一节要干什么
报告分析过程、展示结果，是**证实/证伪假设的经验过程**（彭玉生）。先呈现结果、概括解释主要发现；**紧紧围绕经验发现与假设证实/证伪，理论讨论留到下一节（结论）**。

## 步骤（手把手）
1. **先报结果，再解释**：定量一般用表格简明扼要；把中心问题分解为若干有联系的子问题分章节阐述，最后联系总结（张静）。
2. **表文配套**（read_quant 黄金法则）：表格里出现的数字正文都要讲到；正文点出表中哪些数字重要、正/负系数意味着什么。
3. **解释回归/统计结果时两问**：① 有变量显著吗？② 若显著，方向是否符合预期？（显著性=可排除偶然；星号越多越自信）。
4. **模型递进**：通过加控制变量（holding them constant）隔离核心效应；说明为何加这些控制。
5. **稳健性（robustness）**：换数据/换测量/换规格仍成立，才叫 robust。
6. **机制 / 异质性 / 交互效应**：机制分析（宏观/具体/过程三路径）；交互效应（某变量效应随另一变量而变）。
7. **资料多元性**（张静）：多元多途径来源比单一更有说服力；一手（亲获，注意匿名伦理）/ 二手（须注明来源与第一获得者）/ 视听（须注全）。

## 反模式
- 资料像讲故事铺陈，无精心组织无结论提炼；或只陈述资料不加说明（不同人看到不同）。
- 资料与分析比例不当（只有资料无分析 / 只有分析无资料）。
- 把"相关"当地"因果"——未交代识别策略/控制变量/稳健性。
- 把理论讨论塞进分析节，应留到结论。

## 自检清单
- [ ] 结果是否先呈现、再解释，且紧扣假设？
- [ ] 每个表格是否都有正文配套解释（含方向/显著性）？
- [ ] 是否交代了控制变量、识别策略与稳健性？
- [ ] 是否避免了在分析节做理论推论（留给结论）？
- [ ] 证据是否多元、来源是否如实标注？

## 增补：Edwards「完整故事」+ Kail「先给结论」
- **Edwards**：学术伦理要求**呈现完整故事**——报告未预料/矛盾的发现并尽力解释；语气"自信断言 + 承认不支持之处"。
- **Kail**：结果的"照片"= 子标题/表/图；**子标题要陈述发现，而非只标主题**（"尽管媒体如此呈现，身为酷儿并快乐是常态" > "媒体与酷儿身份"）；**先给结论（lead with the lede）**，别把结果写成悬疑小说；**图优于表**（呈现模式），表用于描述统计与精确值。
