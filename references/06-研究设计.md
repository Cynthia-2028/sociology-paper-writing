# 06 研究设计（理论框架 / 假设 / 变量 / 方法）

> 模板见 `../templates/研究设计.md`。

## 这一节要干什么
把"研究问题"翻译成"可检验的研究设计"：理论框架（分析工具）+ 假设（待验证命题）+ 变量与操作化 + 资料与方法。彭玉生把这部分列为"操作化阶段"（测量/数据/方法），是社会科学称"科学"的可程序化部分。

## 步骤（手把手）
1. **理论框架陈述**：说明采用的分析工具（如博弈论、理性选择、某中观理论）及选用理由；它与文献回顾的关系——理论/分析概念决定分析思路，使观点定位于理论争鸣（张静）。**用范式=接受其预设**，须明了基本预设与针对性；避免一味求"新"（新≠创新，只换语言重说一遍是"装修"非进步）。
2. **构建假设**（彭玉生）——假设是从文献/理论产生的对经验问题的回答，是**连接理论与经验数据的桥梁**，必须可直接检验：
   - 三种构建方式（按与理论密切度）：应用普遍理论 / 间接演绎 / 直接演绎。
   - 三种验证策略：证实单一假设 / 证伪单一假设（"稻草人"战术，须言之有理论有据）/ **仲裁竞争假设（最稳妥）**。
3. **概念界定**：列出原始出处定义；有歧义则比较选择并说明；新概念仅当能概括新现象并推进知识才有生命力（警惕"概念泡沫"）。变量有两层定义（概念层/操作层）。
4. **变量与操作化**：明确自变量/因变量如何测量；说明取值概念与变量概念不可混淆（如"差序格局"是变量概念，其两个取值是"差序格局/团体格局"）。
5. **方法与资料**：描述资料来源/搜集过程并评估可靠性；说明分析技术策略（案例说明设计，或统计说明类型 OLS/Poisson/Logit 等、写回归方程、明确核心变量与控制变量），给足技术细节使可复制。
6. **三点定位（triangulation）**（彭）：理论推理 + 个案分析 + 统计验证三结合；定量定性不互斥。

## 反模式
- 只有领域没有问题（"研究国家与社会的关系"只是问题域非问题），未分解为可用问号的具体问题。
- 假设不可直接检验（理论未操作化）。
- "中国特殊所以西方概念不适用"多数指变量本身相关、只是取值独特——别据此放弃概念。
- 方法细节不足，他人无法复制。
- 概念泡沫：新概念接踵而至，但有关现象的知识并未真正进展。

## 自检清单
- [ ] 理论框架与分析概念是否明确了？与文献对话是否清晰？
- [ ] 假设是否可直接检验、是否连接了理论与数据？
- [ ] 关键概念是否两层定义清晰、操作化可落地？
- [ ] 资料来源、方法、分析技术是否细致到可复制？
- [ ] 是否用了多点证据/三角验证增强说服力？

## Edwards 的 who / what / how
数据与方法节讲清三件事：**样本（who，读者据此判断可推广性）／测量（what，变量如何操作化）／分析策略（how，怎么处理数据）**；并交代数据来源、可靠性、抽样代表性——这些细节常被漏掉，却是审稿人判断严谨性的关键。
