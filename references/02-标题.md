# 02 标题

> 模板见 `../templates/标题.md`。

## 这一节要干什么
标题给读者**期待**，须能传达内容信息。张静三原则：**直接**（直指主题）、**清晰**（不繁复绕口）、**简明**（不冗长重复）。

## 步骤（手把手）
1. **用指涉观点的陈述句**作题（最常用）；少数可用问句。
2. **慎用否定式，不用情绪化词汇**——标题是学术门面，不是噱头。
3. 题目要"小题大做"：聚焦一个清晰对象，而非包罗万象。
4. 写完引言与结论后**回看标题**：标题是否准确概括了你真正回答的问题？不匹配就改标题（别为吸引眼球起新奇题而内容贫乏，适得其反）。

## 反模式
- 题目过大、过长、过于抽象（换到任一篇都可用）。
- 为吸引注意起新奇题，但内容撑不起 → 读者感到被误导。
- 用情绪化/价值判断词（"论 XX 的悲哀"式）。

## 自检清单
- [ ] 标题是陈述句（或必要时的问句）吗？
- [ ] 直接、清晰、简明三原则都满足吗？
- [ ] 别人只看标题能猜出论文大致在回答什么吗？
- [ ] 标题与正文实际结论一致吗？
