# 05 文献综述

> 模板见 `../templates/文献综述.md`。这是最易翻车的一节，请重点读。

## 这一节要干什么
文献综述的目的**不是罗列书单、炫耀所知，而是寻找自己研究问题的价值**（张静）。它要做三件事（彭玉生）：
1. **澄清贡献**——证明自己有新贡献（新理论或新数据）；与著名理论"攀关系"重要，"与前人划清界线"更重要。
2. **提供理论框架**——寻找理论视角是综述最重要功用，理论让事实产生新视角。
3. **提供理论缘由**——证明研究有意义。

Machi 进一步把综述定义为**论证（argument）而非报告（report）**。

## 步骤（Machi 六步法）
1. **Select & Define a Topic**：把个人兴趣转译为研究问题，关联到恰当学科，写出初步主题陈述。
2. **Develop Tools of Argumentation**：掌握 claim（主张）/ evidence（证据）/ warrant（证据连到主张的逻辑桥）/ backing / fallacies（谬误）。
3. **Search**：选择要 review 的文献 → 做检索 → 在检索中**收敛主题**。
4. **Survey**：汇总（catalog）→ 组织信息以建构证据 → **分析数据模式（做 map）**。
5. **Critique**：从描述性论证推进到蕴涵性论证；识别 fallacies；构建 advocacy argument（为你的立场辩护）。
6. **Write**：先"为理解而写"（笔记/探索性写作/提纲/初稿），再"为被理解而写"（多稿修订）。

## 关键操作：map + argument
- **好综述五软标准**（彭）：① 前沿性 ② 覆盖性（**尤其包括与你假设/发现不一致的文献**）③ 相关性 ④ 分析而非堆砌（按理论视角归类、比较差异、批判评估）⑤ 连贯性（始终围绕一条主线，推演出研究假设）。
- **建立"针对性"清单**（张静）：寻找针对性结论（若他们说不对，为何不对）、问题进展与辩论、差异原因、评论贡献与局限、总结主流趋势、说明自己问题与一般性问题的关联。
- **技术纪律**：述与评比例适当；礼貌中性语言；评论针对文章而非作者；避免动机猜测/水平品德政治评判/居高临下断言。

## 反模式
- 无明确针对性观点，以流派/板块为线索像教科书。
- 重在描述而非评估比较；抄他人综述省事（风险：他人问题非你问题，若理解有误则继承错误）。
- 只回顾支持自己的文献，回避对立文献。
- 把综述写成"某人说了 X，某人说了 Y"的流水账，没有论证主线。

## 自检清单
- [ ] 综述是否在论证一个立场，而非罗列？
- [ ] 是否涵盖了与自己发现**不一致**的关键文献？
- [ ] 是否按理论视角归类并比较，而非按作者/时间罗列？
- [ ] 是否推出了本文的研究问题/假设（连贯性）？
- [ ] 是否避免了针对作者的人身/动机评判？

## 综述的立场与相关性（Edwards / Kail / Martín）
- **Edwards**：综述是"**选择性但公正**"的处理，不是全扫描；说明"已知什么、尚待发现什么"，并为你问题的合理性与重要性辩护。先定三个决定：**纳入什么 / 多长 / 怎么组织**（取决于规则设定者与读者）。
- **Kail**：文献/理论/背景的目标是**逐步建立论证**——先列出论证的每一步，再逐条用证据与理论坐实。
- **Martín 相关性三支柱**：共同辩论（用综述搭桥）、期刊定位、期刊读者；不熟悉的文献要"搭桥"引介。
