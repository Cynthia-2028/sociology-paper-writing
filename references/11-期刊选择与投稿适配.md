# 11 期刊选择与投稿适配

> 模板见 `../assets/templates/期刊选择.md`。**动笔之前先读这一节**。

## 这一节要干什么
Martín（Current Sociology 主编）：**没有"通用的好论文"，好论文是"为某本期刊而写"**。先定期刊，再决定写什么、怎么写。

## 步骤（手把手）
1. **先定期刊**：读目标刊近几期，看它发什么、谁在发、被引什么。
2. **评估三特征**（Martín）：
   - **地理/语言范围**：全国性 / 区域性 / 国际性（刊名常误导，须看 aims & scope）。
   - **通识 vs 专门**：通识刊要更开放、少行话；专门刊可更技术化。
   - **格式与偏好**：IMRaD（描述性/定量常见）vs 叙事型 IBC（理论/定性常见）；有无理论/方法偏向。
3. **结构适配**：
   - **IMRaD**：Introduction → Methods → Results → Discussion（硬科学范式，社科美国刊常见，适合描述/定量）。
   - **叙事 IBC**：Introduction / Body / Conclusion；比例约 **15% / 75% / ≤10%**（Martín）。
4. **相关性三支柱**（Martín）：共同辩论（用文献综述搭桥）、期刊定位、期刊读者。**相关性是作者建构的，不是题目自带的**。
5. **对照审稿清单**（Sage / Sociology）：社会学相关性贯穿全文；论点清晰；原创性；嵌入文献；可外推到更广语境；方法/分析严谨；结构清晰；英语清楚；守字数；Harvard 完整参考文献。
6. **投稿前**：精读投稿指南与字数；写 **cover letter 给具名主编/编辑**（表明你确实想投该刊）；摘要独立撰写（见 03）；**不一稿多投、不 salami slicing**。

## 反模式（Martín 列的"人人都犯"）
- 像学生作业/学位论文：小标题写"Aims and scope""Hypothesis"、PPT 要点直贴、把学位论文某章"略作化妆"就投。
- **描述性文章没有核心社会学问题**——不回答"So what?"。
- 不守投稿指南/字数（编辑常直接拒不合规稿件）。
- 不了解刊物范围与编辑政策，投稿信泛泛称呼"sir or madam"。
- **摘要是引言的复制粘贴**（还塞参考文献）。
- 一稿多投；把"有趣"当"相关"。

## 自检清单
- [ ] 我是否已选定目标刊并读过其近期文章？
- [ ] 文章结构（IMRaD / IBC）与该刊偏好匹配吗？篇幅比例合适吗？
- [ ] 相关性三支柱是否都成立（辩论/定位/读者）？
- [ ] 是否回答了"So what?"、把发现连回核心社会学议题？
- [ ] 投稿指南、字数、参考文献格式是否逐条核对？
- [ ] 是否写了具名 cover letter、且没有一稿多投？
