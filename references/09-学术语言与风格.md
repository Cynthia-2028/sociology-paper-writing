# 09 学术语言与风格

> 模板见 `../assets/templates/`（含语言自检清单）。

## 这一节要干什么
让文章"颜值"与"逻辑"兼得，且**省读者的能量**。张静：基于事实证明确认"论据+论点"，用理性理由（讲道理=给理由而非只给结论），中性学术语言（针对道理而非人品，针对事实而非道德评判）。

## 核心工具 1：读者能量模型（易莉，Gopen）
大脑处理句子能量 **Et = 句法能量 + 语义能量**，单句总能量固定。句法越费劲，留给语义的越少。故写作要**减少读者句法能量消耗**：
- 读者预期：① 动作由动词表达；② 句子先讲最先出现的人/物；③ 谓语紧跟主语；④ 强调内容放在句末；⑤ 句首与上一句有联系。
- 应用：中文长句、嵌套从句最耗能量——能拆就拆，把强调点放到句末。

## 核心工具 2：Strunk 18 条（英语写作底线，关键条）
- 规则 8：以段落为单位，一段一主题。
- 规则 9：通常以主题句开头，结尾首尾呼应。
- 规则 10：**用主动语态**。
- 规则 11：用**肯定形式**陈述。
- 规则 12：用清晰、明确、具体的语言。
- 规则 13：**删掉不必要的词**（Omit needless words）。
- 规则 14：避免连续松散句。
- 规则 15：用相似形式表达并列意思（平行结构）。
- 规则 16：相关词放在一起。
- 规则 17：概述中坚持一种时态。
- 规则 18：把要强调的词置于句末。

## 核心工具 3：论证自检（易莉"玫瑰三段论"）
人会被具体内容干扰而忽略推理结构错误。写/读论证时盯**结构**而非内容：前提是否真能推出结论？相关是否等于因果？

## 去 AI 腔（用户硬规则）
- 避免"在当今社会……日益……具有重要意谧"式空洞套话；避免"值得注意的是""综上所述"的机械过渡。
- 用具体主语+具体动词，少用"本文旨在""本研究通过"的被动堆叠。
- 写完用 Strunk 13（删冗余）+ 能量模型（砍从句）各过一遍。

## 反模式
- 只讲结论/观点/表决心/斥责他人；情绪宣泄；用意识形态代替知识研究。
- 概念泡沫：新概念接踵而至但知识无进展。
- 中文长句嵌套、英文被动堆砌，读者读完全文却不解其意。

## 自检清单
- [ ] 每句的动作是否由动词表达、谓语是否紧跟主语？
- [ ] 是否用了主动/肯定/具体语言、删掉了冗余词？
- [ ] 一段是否只有一个主题？
- [ ] 强调点是否落在句末？
- [ ] 有没有 AI 腔套话/空洞过渡？论证结构是否成立？

## 增补：Kail「手艺」与 Edwards「中立」
- **Kail**：写作是手艺，靠工具 + 练习；句子要有**具体的主语与动词**（少用抽象名词作主语）。
- **Edwards**：避免煽情/夸张/道德指责式语言，保持中立可信。
