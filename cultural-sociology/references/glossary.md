# 概念词典

> 用法：回答「X 是什么意思」时，先查这里；条目格式为 **中文（English）｜所属路线｜一句定义｜出处｜最常见误用**。
> 引文页码一律为 PDF 物理页（与 `_notesS/` 一致）。标「未核实」者不得当作确定事实引用。

## 一、布迪厄路线

**惯习（habitus）**｜布迪厄
「持久的、可转换的倾向系统；被结构化的结构，又倾向于充当结构化的结构」，生成并组织实践，却不预设自觉目标与熟练操作（Swartz PDF p.103；*Outline* PDF p.87）。
→ 误用：当成「习惯」「性格」或「价值观」。它的定义性特征是 **transposable**（可跨领域迁移）。

**场域（field / champ）**｜布迪厄
位置之间的客观关系构型；位置由其在资本分布中的处境、以及与他位置的客观关系（支配、从属、同构）界定（Swartz PDF p.118）。
→ 误用：当成「行业」「领域」「圈子」。没有位置测量，就没有场域。

**场域自主性（relative autonomy）**｜布迪厄
场域依据自身内部等级而非外部权力来分配承认的程度；是**程度变量**，不是有无（Swartz PDF p.126–127）。
→ 误用：说「某个场域是自主的」而不指出它对谁自主、靠什么机制维持。

**占位（position-taking）**｜布迪厄
行动者在场域内占据的具体立场、作品、主张、联盟；与「位置（position）」不同，占位是位置的表征（Swartz PDF p.131）。
→ 误用：把两者混用，导致「同构」变成同义反复。

**同构（homology）**｜布迪厄
两个空间之间「差异中的相似」（a resemblance within a difference）：结构对应，内容不同（Swartz PDF p.128）。
→ 误用：把「相关」说成「同构」。同构要求两套位置结构一一对应。

**场域权力（field of power）**｜布迪厄
各场域精英相互竞争、并共同统治的元场域；具有「交叉结构」（chiasmatic structure）（Swartz PDF p.134–137）。
→ 误用：等同于「国家」或「政治」。

**资本（capital）**｜布迪厄
在场域中被承认、可积累、可兑换的资源；分经济、文化、社会、象征四类（Swartz PDF p.78）。
→ 误用：只算经济资本，然后把文化当「影响因素」。

**文化资本三形态**｜布迪厄
具身化（embodied，长期浸润成的身体与心智倾向）、客体化（objectified，物与作品）、制度化（institutionalized，文凭、资格、称号）（Swartz PDF p.79–80）。
→ 误用：只测客体化（读什么书、看什么展），忽略具身化最难测也最要害。

**资本汇率（exchange rate）**｜布迪厄
不同资本之间兑换的比例关系，且不对称——经济资本可较容易转为文化资本，反之更难（Swartz PDF p.78、p.83）。
→ 误用：假设资本可自由互换。

**象征资本（symbolic capital）**｜布迪厄
被否认的、被承认为正当的资本；它只有在他者承认时才存在（Swartz PDF p.92–95）。
→ 误用：当成「名声」的同义词。

**象征暴力（symbolic violence）**｜布迪厄
通过被支配者**共谋**（misrecognition）而生效的支配：支配者与被支配者共用同一套评价范畴（Swartz PDF p.91–92）。
→ 误用：当成「洗脑」「欺骗」。它的关键是**不需要欺骗**，双方都真诚相信。

**误认（misrecognition）**｜布迪厄
把社会任意性误认为自然或正当（Swartz PDF p.92）。
→ 误用：与「承认（recognition）」混为一谈——后者是拉蒙/霍耐特的词，方向相反。

**doxa**｜布迪厄
不被争论的、前反思的共识领域；正统与异端都预设了它（*Outline* PDF p.188、p.192–193）。
→ 误用：当成「意识形态」。doxa 的特征恰恰是**没被说出来**。

**illusio**｜布迪厄
对场域游戏「值得玩」的投入感；参与的前提（Swartz PDF p.125）。
→ 误用：当成「兴趣」。

**正统 / 异端（orthodoxy / heterodoxy）**｜布迪厄
在 doxa 被打破后出现的两种显性立场（*Outline* PDF p.194）。
→ 误用：把异端当成「反抗」；异端仍在同一套分类里。

**滞后（hysteresis）**｜布迪厄
惯习与变化后的场域错位——倾向仍在按旧规则运作（*Outline* PDF p.93；Swartz PDF p.113–114）。
→ 误用：当成「不适应」。它是**变迁研究最有力的入口**。

**文化任意（cultural arbitrary）**｜布迪厄
任何文化秩序的内容都不是必然的，但其任意性被权力掩盖（*Outline* PDF p.186）。
→ 误用：读成「文化都是随意的」——布迪厄说的是「任意性被误认为必然」。

**区隔（distinction）**｜布迪厄
通过品味差异标记并再生产社会差异的过程（*Distinction* PDF p.468–469）。
→ 误用：当成「精英主义」或「装」。

**品味三带**｜布迪厄
合法（legitimate）/ 中俗（middle-brow）/ 通俗（popular）三个区域，对应不同阶级惯习（*Distinction* PDF p.39–40）。
→ 误用：当成固定清单——它是**关系性**的，随场域变化。

**必要品味 / 自由品味（taste of necessity / of liberty）**｜布迪厄
受约束者选择「必需之物」，有闲者选择「多余之物」（*Distinction* PDF p.160–163）。
→ 误用：当成「穷人务实、富人奢侈」的心理学描述。

**审美配置（aesthetic disposition）**｜布迪厄
把形式置于功能之上、把作品当作品看的能力（*Distinction* PDF p.28–32）。
→ 误用：当成「有品味」。

**阶级惯习（class habitus）**｜布迪厄
阶级条件的**内化形式**及其所连带的条件化（*Distinction* PDF p.123）。
→ 误用：当成本质化的「阶级性格」。

**身体姿态（bodily hexis）**｜布迪厄
「体验与表达自身社会价值的实践方式」（*Distinction* PDF p.476）。
→ 误用：忽略它，只测「文化参与」。

**有限生产 / 大规模生产**｜布迪厄
文化生产场的两极：为同行生产（restricted）与为大众市场生产（large-scale）（Swartz PDF p.216–217）。
→ 误用：当成「高雅/通俗」的另一个说法。

**颠倒的经济世界（the economic world reversed）**｜布迪厄
文化场域中「输者为赢」（loser wins）的规律：拒绝商业成功反而获得圣化（Bourdieu 1983, PDF p.10–11）。
→ 注意：`loser wins` 原文仅在 PDF p.10 出现一处；Fowler 用的 `world-in-reverse` 是不同措辞，不可互换。

**圣化（consecration）**｜布迪厄
由场域内权威授予的正当性（Fowler PDF p.87；Swartz PDF p.51）。
→ 误用：当成「获奖」。

**符号边界 / 社会边界**｜拉蒙（布迪厄路线的当代分支）
符号边界是概念上的区分；社会边界是被制度化、被广泛同意的区分。前者是后者的**必要非充分**条件（Lamont & Molnár 2002, PDF p.4）。
→ 误用：把任何「我们/他们」的说法都当社会边界。

**边界工作（boundary work）**｜拉蒙
行动者划定、维护、跨越、拆解边界的实践。
→ 注意：拉蒙**没有**给出一套编号式的「边界工作类型学」；她给的是三套评价标准（道德/经济/文化）＋边界的形式属性（强度、共识度、可渗透性）。

**评价 / 估值（valuation / evaluation）**｜拉蒙
valuation 是价值的生产与赋予；evaluation 是对价值的判定（Lamont 2012）。
→ 误用：只研究「标准」，不研究「谁有权打分」。

**承认（recognition）**｜拉蒙
被看见、被当作完整的人对待；其反面不是「歧视」而是「被无视」（Seeing Others）。
→ 误用：等同「尊重」或「包容」。

**能动性三维（agency）**｜Emirbayer & Mische
iteration（迭代过去）、projectivity（投射未来）、practical evaluation（评估当下）三者的可变组合（PDF p.10）。
→ 误用：把能动性当「有无」的变量。

**协同培养 / 自然成长**｜Lareau
中产阶层「协同培养」（concerted cultivation，有组织的活动+说理）vs 工人阶级/贫困家庭「自然成长」（natural growth，指令+自由玩耍）（Lareau PDF 导论与核心章）。
→ 注意：Lareau 自认是「布迪厄模型的（部分）经验应用」，不是反布迪厄；她的修正是补上「拥有资本 vs 激活资本」与守门人两个环节（PDF p.391）。

## 二、强纲领路线

**强纲领（strong program）**｜强纲领
文化社会学的一种纲领：要求把文化从社会结构中**分析性地解绑**，重构其内部结构，并把因果锚定在具体行动者上（*Meanings* PDF p.26–27）。
→ 注意：名称借自科学社会学的爱丁堡学派，但**原意相反**（Bloor 的强纲领用社会利益解释观念；亚历山大要的是观念自主）。引用时必须说明这是转义（McLennan p.9）。

**文化自主性（cultural autonomy）**｜强纲领
文化结构有自身的模式与逻辑，不能化约为利益、心理或位置（*Meanings* PDF p.26）。
→ 误用：读成「文化决定一切」。自主性说的是「可独立分析」，不是「唯一原因」。

**浓描 / 厚描（thick description）**｜格尔茨 → 强纲领
把行为放回其意义层级中描述，判据是能否区分「眨眼」与「递眼色」（《文化的阐释》PDF p.19、p.29）。
→ 注意：中译本用「浓描」，不是「深描」。

**括出（bracketing-out）**｜强纲领
方法论上先把更广的非象征社会关系「括起来」，造出分析上自主的文化客体（*Meanings* PDF p.27）。
→ 误用：当成「否认社会结构存在」。这是**暂时的分析操作**。

**符码（binary codes）**｜强纲领
组织公共评价的二元对立系统（神圣/凡俗、纯洁/污染、公民/反公民等）（*The Civil Sphere* 第 4 章；*Meanings* 第 5 章）。
→ 误用：当成「主题」「关键词」。符码是**对立结构**，不是词表。

**公民领域（civil sphere）**｜强纲领
独立于国家与市场的意义与团结领域，有自己的符码、制度媒介（法律、选举、媒体、社团）与修补机制（*The Civil Sphere*）。
→ 误用：等同于「公民社会」（civil society）这个组织概念。公民领域是**符号-制度**概念。

**公民修补（civil repair）**｜强纲领
把被排除者重新纳入公民领域的过程与制度努力。
→ 误用：当成「改革」；它特指用公民领域自身的符码进行的修复。

**文化创伤（cultural trauma）**｜强纲领
事件本身不构成创伤；创伤是集体通过意义工作**归因**为「对我们根本性的伤害」（*Meanings* PDF p.98–107；*Cultural Trauma and Collective Identity* PDF p.21–35）。
→ 误用：把「很多人受害」当成文化创伤。

**创伤过程（trauma process）**｜强纲领
主张者 → 受众 → 情境定义 → 载体群体 → 制度场域 → 记忆 → 例行化 的七步过程。
→ 误用：跳过「谁在主张」，直接说「社会受到创伤」。

**载体群体（carrier group）**｜强纲领
承载并推进某一创伤叙事的群体（知识分子、受害者组织、媒体等）。
→ 注意：中国研究里「没有载体群体」常是**否定性推断**，必须区分「不允许承载」与「没人想承载」。

**社会表演（social performance）**｜强纲领
把集体表象、演员、观众、象征生产手段、舞台调度、社会权力组合起来的意义传递过程；成败可分析（*The Drama of Social Life*）。
→ 误用：当成隐喻。它是一个**可操作的分析框架**。

**文化语用学（cultural pragmatics）**｜强纲领
研究文化结构如何在实际情境中被「演出」、融合或去融合的理论（*The Drama of Social Life*；**注意**：该书没有编号式六要素清单，最完整的罗列在 PDF p.40，实为八项；通行「六要素」出自 2004/2011，页码未核实）。

**融合 / 去融合（fusion / de-fusion）**｜强纲领
表演要素与受众经验合一 / 断裂的状态；去融合有六类来源（脚本不匹配、演员失信、观众不投入、生产手段被夺、舞台失误、权力压制）。
→ 误用：把「传播广」当融合。

**脚本（script）**｜强纲领
表演所依据的意义文本，含背景表象与情节。
→ 误用：当成「台词」。

**舞台调度（mise-en-scène）**｜强纲领
时间、地点、路线、服装、道具、镜头的实际安排。
→ 误用：当成「布景」；它包含**时序与悬念**。

**象征生产手段（means of symbolic production）**｜强纲领
使表演可被看到的物质与制度条件（媒体、场地、技术、资金）。
→ 误用：只记「有没有被封」，漏掉「有通道但无分发」。

**图像权力（iconic power）**｜强纲领
图像通过表面/深度（surface/depth）结构承载并浓缩意义的能力（*Iconic Power*）。
→ 误用：当成「视觉冲击力」。

**图像经验（iconic experience）**｜强纲领
观者在一件图像/物中同时经验到表面与深度的时刻（Giacometti 分析）。
→ 误用：当成「审美体验」的心理学描述。

**社会化 / 社会危机（societalization）**｜强纲领
一个社会问题从特定制度场域溢出、被公民领域承认为全社会危机的过程（*What Makes a Social Crisis?*）。
→ 误用：等同于「社会问题严重化」。它特指**跨场域的转译**。

**社会戏剧（social drama）**｜Turner
breach → crisis → redress → reintegration 的过程结构（Turner 1980）。
→ 注意：亚历山大使用「阈限/社会戏剧」概念，但**未逐条照搬四阶段**；引用时区分「Turner 原框架」与「亚历山大转用」。

**阈限（liminality）**｜Turner
仪式中脱离日常结构的中间状态。
→ 误用：泛化为「过渡期」。

**文类（genre）**｜强纲领
叙事的意义组织形式（英雄/浪漫/悲剧/喜剧/反讽），决定事件被如何理解（*Meanings* PDF p.214–217）。
→ 误用：当成「文体」。

**frontlash / backlash**｜强纲领
frontlash 是先行推进某一议程、随后引发 backlash 的序列关系，**不是对称的两极**（*Frontlash/Backlash* PDF p.1–5）。
→ 误用：写成「前进与反扑两股力量」。

**社会疼痛（social pain）**｜强纲领
集体层面的痛苦经验，需被文教化（cultured）才成为创伤（Abrutyn 2024）。
→ 注意：这是理论整合型概念，经验检验困难。

## 三、计算测量路线

**测量文化（measuring culture）**｜计算
把意义当作可观察、可比较的对象来处理的一整套方法论立场（Mohr et al. 2020）。
→ 注意：其合法性来自「解释是有模式的」（PDF p.14），不是「意义有边界」。

**意义结构（meaning structure）**｜计算
在特定语料/关系中被稳定复现的意义组织方式。
→ 误用：当成「文化」本身。

**局部意义系统（local meaning system）**｜计算
被明确划定的语言共同体、场景、时间窗、体裁所构成的分析边界。
→ 注意：Mohr et al. 2020 全书**没有**这个术语（笔记标未核实其出处）；写作时改用 "in situ"、"bounded system of symbolic meanings" 等原文表述。

**2×2 范式格（Mohr & Rawlings 2010）**｜计算
以「文化转向前/后」× 「是否以解释学为目标」分出四格：Kroeber（意义在风格变异）、Lévi-Strauss（意义在关系束的对立）、DiMaggio（意义在指涉关系中）、White（意义在关系构型本身）。
→ 误用：把这四格当成 Mohr et al. 2020 的「四条路径」——那本书的骨架是三层（人/物/关系）。

**分布假设（distributional hypothesis）**｜计算
一个词的意义由它的共现语境决定。
→ 注意：强式不成立，弱式近乎空洞，中间层（语料共同体的用法结构）才站得住。

**词嵌入（word embeddings）**｜计算
把词映射为向量，使语义相似表现为向量接近（共现 → PPMI → SVD / 预测式模型）。
→ 误用：把余弦距离直接当「意义相似」，忽略句法、拼写、固定搭配造成的非语义关联。

**文化维度 / 语义维度（cultural dimension）**｜计算
由一对锚词（如 rich–poor）定义的语义方向，可用来给词或群体定位（Kozlowski 等）。
→ 注意：轴是**研究者指定的测量工具**，不是算法发现的；必须报告端点平衡与稳健性。

**历时嵌入（diachronic embeddings）**｜计算
分时段训练并对齐（Procrustes）后的词向量，用于测语义漂移（Hamilton 等）。
→ 误用：不对齐就比较；把语料构成变化读成语义变化。

**主题模型（topic model, LDA）**｜计算
文档—主题—词三层生成模型，用词共现簇表示「话题」。
→ 误用：把 K 当真实类别数；用 top terms 直接命名；把主题当符码。

**结构主题模型（STM）**｜计算
允许主题流行度与内容随文档协变量变化的主题模型（Roberts 等）。
→ 注意：协变量若内生，结论不能读成因果。

**语义连贯性（semantic coherence）**｜计算
主题内部高频词在语料中共同出现的程度，用于评估主题可解释性（Mimno 等）。
→ 注意：coherence ≠ 文化重要性；对小主题有系统性歧视。

**关系性方法（relational approach）**｜计算
把文化当作行动者—实践—话语之间的网络构型来测（二模网络、块模型、对应分析、关联规则）。
→ 与分布性方法的差别：分布性测**语言共同体的用法结构**，关系性测**社会共同体的选择结构**。

**对应分析（correspondence analysis, CA/MCA）**｜布迪厄 / 计算
把行（行动者）与列（实践/品味）投影到同一空间，用距离表示关联。
→ 注意：它是**描述性**的空间技术，不是因果模型。

**关联规则 / RULeNet**｜计算
用「A→B」的有向蕴含刻画品味结构，并区分统一者、分化者与门槛（Gondal）。
→ 注意：三个阈值靠惯例；横断面数据不能推断方向。

**微类型（microgenre）**｜计算
粗糙标签内部的有社会意义的亚型；用链接聚类从条目层数据中析出（Lizardo）。
→ 误用：把聚类结果直接当类型，不做稳定性检验。

**品味三模态**｜计算/概念
偏好（preference）、消费（consumption）、评价（evaluation）是三种不同模态，可能不一致（Ma）。
→ 误用：用单模态代理多模态。

**伪项目（pseudo-item）**｜计算
虚构的文化项目，用来区分「真的知道」与「倾向性开放/话语权」（Childress）。
→ 注意：中国语境需本土化设计；「不知道」选项缺失即失效。

**验证（validation）**｜计算
无金标准时的四种替代：替代标签、部分类别复现、非专家判别（含 intruder detection）、外部信息对应（Grimmer 等）。
→ 误用：同一批数据既训练又检验。

**FPCILV**｜计算
「先分类、后推断」的效度陷阱：先用文本把样本分类，再把这些类别当自变量做因果推断，会系统性高估效应（Grimmer 等）。
→ 对策：先切样本、先固定映射函数。

**语料偏倚（corpus bias）**｜计算
语料相对目标总体的系统性偏差（资源、激励、媒介、检索四类）。
→ 对策：写清 population → sampling frame → 实际语料，并做体裁平衡的稳健性检验。

## 四、后殖民与跨路线概念

**殖民性权力（coloniality of power）**｜后殖民（Quijano）
殖民关系结束后仍持续运作的分类与支配装置，以「种族」为社会分类的轴心（Quijano 2000）。
→ 注意：Quijano 该文**没有**「colonial matrix」一词（那是 Mignolo 的措辞）。

**欧洲中心主义（Eurocentrism）**｜后殖民
把欧洲置于历史中心与终点、并把欧洲/非欧洲差异自然化的知识结构。
→ 注意：Quijano 该文没有「两种神话」的提法；可确证的是两个机制——身体被客体化、时间被位移。

**落后（luohou / lagging behind）**｜后殖民（Meinhof）
一套把空间差异转译为时间差异的话语装置；「落后就要挨打」是一个已被自然化的集体表象。
→ 用法：可作为强纲领意义上的「二元符码（先进/落后）」来研究。

**双重权力结构**｜后殖民（Meinhof）
两套政治立场相反的反话语共享同一套时间语法——批判者与赞美者都在生产「现代性等级」。
→ 风险：容易写成「无所不在的权力」，取消能动性；需用 Emirbayer & Mische 的三维对冲。

**反公共领域（counterpublic）**｜强纲领/文化研究
相对于主流公共领域、自建话语规则与受众的亚群体空间。
→ 注意：「双重矛盾」（dual ambivalence）指它同时反抗与借用主流评价语汇（Cui 2026）。

## 五、计算社会学补编（2026-10-21 并入）

**文化种类（cultural kinds）**｜计算社会学
在文化分析中被当作核心解释因子的所有实体，无论简单或复杂；作者明说这是一个「杂牌军」，故**追求「文化」的统一界定是徒劳的**（Lizardo 2026, PDF p.2）。
→ 误用：以为这个概念在给「文化」下定义。它是在**编目**，不是在界定。

**本体论主张（ontic claims）／认识论主张（epistemic claims）**｜计算社会学
前者是关于「文化是什么」的显性与隐性假定；后者是关于「既然它是这类东西、该怎么研究它」的主张。**两者必须分开**，因为多数「方法之争」其实是本体论之争被误读成方法之争（Lizardo PDF p.2–4）。
→ 误用：从「文化本质上是公共的」直接推出「必须做民族志」——这是用一个未检验的本体论主张替代方法论论证。

**四类本体论主张**｜计算社会学
**构成**（由什么材料构成）、**位置**（存在于何处：人内/人外）、**属性**（使它成为它自身的特征，如共享性、系统性）、**发生**（凭什么算文化：来源是否依赖人的创造）（Lizardo PDF p.4–8）。
→ 误用：当成四个互斥门派。它们是分析维度，通常成捆出现（"come in bundles"，p.6–7）。

**群体主义谬误（groupist fallacy）**｜计算社会学
把「共享」当作文化的定义性属性，从而让「被复制」这一关系性属性把同一实体从「非文化」变形为「文化」，并把「群体」当起点、阻止研究共享如何产生（Lizardo PDF p.9）。
→ 金句：「要有多少人共享某物，它才越过那条看不见的界线？」（PDF p.9）

**解释（interpretation）**｜计算社会学
「一个刺激与一个被认知表征的概念相联结的过程」；操作性定义是判定「某物是什么」的认知过程（Goldberg & Singell 2024, PDF p.3）。
→ 误用：与「态度」「行为」混为一谈。解释是认知判定，不是好恶，也不是行动。

**归类（categorization）／语义联想（semantic association）**｜计算社会学
归类＝刺激激活某概念（「这是什么」），可写作 P(c|s)；联想＝该概念进一步激活一组相联概念（「它像什么」），可写作 P(a|c)（Goldberg & Singell PDF p.5–7）。
→ 误用：只用词频或主题做「联想」，却声称测了「归类」——两者不是一回事。

**解释异质性（interpretative heterogeneity）**｜计算社会学
群体成员解释分歧的程度。研究态度/行为差异时，必须先把解释异质性与态度差异分开（Goldberg & Singell PDF p.11）。
→ 注意：**模糊**（刺激落在概念边界上）与**争议**（人与人的表征不一致）在总体分布上形状相同，不能靠分布形状区分（p.10 边栏）。

**共享归类／共享联想**｜计算社会学
S(P_i(c|s), P_j(c|s)) 与 S(P_i(a|c), P_j(a|c))；前者可用 Jensen–Shannon 散度测。两者不必重合，故「思想共同体」要沿两个维度分别划界（Goldberg & Singell PDF p.9–11）。

**计算扎根（computational grounded theory, CGT）**｜计算社会学
Nelson 的三步框架：模式发现（比例差/词分 + 主题模型）→ 模式精炼（按主题权重取代表文档深读）→ 模式确认（监督学习 + 词典 + NER 全语料核验）（PDF p.1、p.9–31）。
→ 注意：**同名不同物**。陈茁、陈云松的「计算扎根」是变量侧的（定 Y → 预测 → SHAP 归因 → 理论抽象），与 Nelson 的文本侧不是一回事。

**计算机辅助文本分析（computer-assisted, CALM）**｜计算社会学
Carlsen & Ralund 对 CGT 的替代：人是 ground truth，模型只做检索与规模化；流程为发现（簇词+扩词+snowball）→ 扎根（常数比较、造编码本）→ 分类（主动学习）→ 效度（大测试集、分组偏差）→ 测量（PDF p.11–14）。
→ 误用：以为它只是 CGT 的简化版。它拒绝的是 CGT 对无监督模型的三条假设。

**直接效度（direct validity）**｜计算社会学
用随机抽样的人工编码算 precision/recall，并把测试集做得足够大以**按子群诊断偏差**；与「与某个外部指标相关」的间接效度相对（Carlsen & Ralund PDF p.10–14）。
→ 误用：只报总体准确率。子群系统偏差会被平均掉。

**社会预测（social prediction）**｜计算社会学
把预测立为社会学研究的新范式，而不只当作统计副产品；三种工具性用法：潜藏指标（用可测变量预测不可测变量）、反事实（若未发生某事）、数据增生（陈云松等 2020, PDF p.8–20）。
→ 误用：把「预测」当「解释」。预测力高只说明 X 是因果候选，不说明 X 是原因。

**联想矩阵／文化结构（structure of culture）**｜计算社会学
把文化重述为「什么和什么搭配」（what goes with what）的分布性理解，由个人与组织行动者共同采纳而扩散（Lizardo & Jilbert 2023）。
→ 用途：让文本共现、组织数据、消费数据可以放进同一测量框架比较。
