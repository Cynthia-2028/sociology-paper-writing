# 七类任务的操作手册

> 用法：先按 §0 判断任务类型，再跳到对应小节。每一节都给了**输出结构、必须包含、禁止、模板**。
> 通用纪律：先给结论/答案，再给依据；不编造文献；概念必须落到原作者；三条路线的标签不可混用。

---

## §0 任务路由表

| 用户说的话 | 任务类型 | 是否问路线 | 读哪个文件 |
|---|---|---|---|
| 「文化社会学是研究什么的」「什么是象征暴力」 | 科普 / 答题 | 不问（概念题按归属答） | `glossary.md` |
| 「用文化社会学解释一下××现象」 | 解读现象 | **问** | `route-comparison.md` |
| 「带我系统学文化社会学」「制定阅读计划」 | 学习 | 不问（给三条并行的学习路径） | `canon.md` |
| 「我想研究××，有什么选题」 | 选题 | **问** | 本文件 §4 + `debates.md` §5 |
| 「帮我写××的论文/引言/理论框架」 | 写作 | **问**（必须） | 本文件 §5 |
| 「帮我看看这篇论文怎么样」 | 评审 | 先判路线，再评 | `review-rubric.md` |
| 「这本书讲了什么」「帮我读这篇」 | 精读导读 | 不问 | `canon.md` + 对应路线文件 |

## §1 知识科普

**目标**：让没有社会学背景的人，在 3 分钟内拿到一个能用的概念，而不是记住一堆人名。

**结构（固定五段）**
1. **一个钩子**：一个日常困惑或反常识现象（「为什么你觉得某些东西『俗』？」）。
2. **一个核心概念**：只讲一个，给中文+英文，给一句人话定义。
3. **一个对照**：这个概念**反对**什么常识解释（没有对照，概念就没有锋利度）。
4. **一个例子**：中国的、具体的、有时间地点的。
5. **一条边界**：它解释不了什么 / 被谁批评。

**禁止**
- 罗列人名与年份（「韦伯、涂尔干、布迪厄都……」）。
- 用「建构」「场域」「惯习」解释「场域」「惯习」。
- 把三条路线的说法混成一段（「文化既是资本也是自主结构还是可测量的分布」——读者会疯）。

**示例开头（可直接改用）**
> 你先想一件事：为什么同样一份工作，有人觉得「体面」，有人觉得「没出息」？布迪厄的答案是——「体面」不是工作的属性，是**评价者站的位置**的属性。他把这套东西叫「惯习」……

## §2 解读一个社会现象

**目标**：给一个「有机制的解释」，不是「有立场的评论」。

**五步（必须按序）**
1. **定客体**：把现象收窄成一个有边界的对象（哪段时间、哪个平台、哪些人、什么文本/事件）。边界不清，后面全是空话。
2. **选路线**（见 `route-selection.md`），并说明为什么这条路线适合这个客体。
3. **找结构**：
   - 布迪厄：谁在什么位置、用什么资本、换什么；
   - 强纲领：哪两组对立在组织这件事（神圣/污染、公/私、真/表演）；
   - 计算：哪些话语丛、份额、时序。
4. **排过程**：这件事怎么一步步变成现在这样（时间线/阶段/转折点）。
5. **给反例**：有没有不符合这个解释的案例？如果有，解释为什么。

**输出模板**
```
## 一句话结论
（一个机制句，不是价值判断句）

## 为什么不是常识解释
（常识解释是什么，它漏了什么）

## 机制（分 3–4 步）
1. … 2. … 3. …

## 证据
（具体材料；没有材料就明说「这是推论」）

## 反例与边界
（这个解释覆盖不到的情况）

## 如果要用这条路线做研究
（数据、方法、最小可行版本）
```

**禁止**
- 用「资本」「规训」「景观」当形容词。
- 只给批判不给机制（「这是资本逻辑」不是解释）。
- 把「我认为」写成「研究表明」。

## §3 解答专业问题 / 学习知识点

### 3.1 单点提问（「什么是 X」）
**结构**：定义（原作者原话的中译）→ 出处 → 它反对什么 → 一个例子 → 最常见的误用 → 它在另一条路线里会被怎么批评。

**必须做的两件事**
1. 说清它属于哪条路线（同一个词在三条路线里可能意思不同，例如「文化资本」在计算路线里会被操作化为「文化参与得分」）。
2. 给一个「相邻概念」的辨析（惯习 vs 习惯；符码 vs 主题；边界 vs 分类）。

### 3.2 系统学习（「带我学」）
给一条**三线并行**的路径，不要只给一条：

| 周次 | 布迪厄线 | 强纲领线 | 计算线 |
|---|---|---|---|
| 1 | Swartz 前 3 章 | 《社会生活的意义》第 1 章 | 《Measuring Culture》导论 |
| 2 | 《区隔》导论 + 三带 | 符码章 + 一个案例 | Mohr & Rawlings 2×2 |
| 3 | 场域三步骤 + 一篇经验研究 | 《社会生活的戏剧》 | 词嵌入/主题模型各一篇 |
| 4 | 写一个 800 字的小分析 | 写一个 800 字的符码分析 | 用公开语料跑一遍流程 |

**配套**：每周给 3 道自测题（1 道定义题、1 道辨析题、1 道应用题），下一周先回收答案再进新内容。

### 3.3 回答「三派有什么不同」
不要背表。用**同一个例子**过三遍（见 `route-comparison.md` §1–§2），让差异在例子里显形。

## §4 探讨选题

### 4.1 选题的四个合法来源（按可靠性排序）
1. **文献自陈的缺口**：`strong-books-3.md` 里手册的 20 个方向、`debates.md` §5 的 Q1–Q8。这些是作者自己承认没解决的问题。
2. **方法错配**：现有研究用了不匹配的方法（用问卷测惯习、用访谈测双过程）。指出错配本身就是贡献。
3. **中国经验的不可翻译**：某个西方概念在中国语境里找不到对应物（如「公民领域」）。此时正确做法不是硬套，而是**重建问题**。
4. **材料新可得**：新平台、新档案、新数据使旧问题可答。

### 4.2 选题评估矩阵（每次给 3–5 个候选，逐个打分）
| 维度 | 问什么 | 1 分 | 5 分 |
|---|---|---|---|
| 理论贡献 | 它改变了哪场争论？ | 只是换了个案例 | 让两派必须回应 |
| 数据可得 | 三个月内能拿到吗？ | 需要不可能拿到的档案 | 公开语料/可访谈 |
| 方法匹配 | 方法与机制是否对得上？ | 用问卷测具身图式 | 识别策略与机制一致 |
| 可证伪 | 什么结果会推翻它？ | 怎么都成立 | 有明确的否证条件 |
| 伦理与风险 | 涉及敏感人群/审查风险？ | 高风险且无预案 | 低风险 |
| 写作可控 | 能在 8000–12000 字内讲完？ | 三个大问题 | 一个机制 |

**总分低于 18 分的选题，直接建议放弃**（并说明哪一项拖后腿）。

### 4.3 选题卡模板（输出给用户可直接用）
```
题目（工作标题）：
一句话问题：（不是主题，是问句）
路线：布迪厄 / 强纲领 / 计算（+ 辅助路线）
核心机制：（一句话）
数据：（来源、规模、时间窗）
识别策略：（怎么排除替代解释）
预期贡献：（改写哪场争论/提供什么概念）
最大风险：（一条，附预案）
最小可行版本：（如果只有 1/3 资源，怎么降级）
```

### 4.4 选题的三个「不要」
- 不要做「中国人重视 X 吗」——答案几乎总是「重视」，不构成发现。
- 不要做「用中国案例验证西方理论」——除非你能指出该理论在中国的**失效点**。
- 不要三个机制一起做——一篇论文只能有一个主张。

## §5 撰写论文

### 5.1 先定路线，再定骨架
| 路线 | 骨架 | 篇幅分配（以 10,000 字计） |
|---|---|---|
| 强纲领 | **COPE-R**：悖论钩子 → 文化客体 → 符码解码 → 过程 → 证据 → 理论回响 | 钩子 800 / 客体 1,200 / 符码 2,000 / 过程 2,200 / 证据 2,300 / 回响 1,500 |
| 布迪厄 | 问题 → 场域构型 → 资本与位置 → 惯习与错配 → 再生产闭环 → 讨论 | 问题 1,000 / 场域 1,800 / 资本 2,000 / 惯习 2,200 / 闭环 1,800 / 讨论 1,200 |
| 计算 | 问题三元组 → 语料 → 测量 → 验证 → 发现 → 解释学回归 → 局限 | 问题 1,000 / 语料 1,500 / 测量 2,000 / 验证 2,000 / 发现 2,000 / 回归 1,000 / 局限 500 |

### 5.2 COPE-R 六段的写法（强纲领）
- **第 0 段 悖论钩子**：不写「某现象很重要」，写「某现象按理不该如此」。例：黑胶在最不便携的时代复兴；自称「废物」的人其实是精英。
- **第 1 段 文化客体**：界定分析单位的边界（何时开始、何时结束、谁在其中）。这一步替代量化论文的「操作化」。
- **第 2 段 符码解码**：找出二元结构，并说明它如何组织评价。替代「因果模型」的位置。
- **第 3 段 过程**：把静态结构变成时间序列（四阶段/融合-去融合/创伤七步）。
- **第 4 段 证据**：五种装置可叠用——时间戳与互动量、引文配对（正例+反例）、档案对勘、效应量与空间位置、外部指标。
- **第 5 段 理论回响**：铸造一个概念，并说明它改变了哪场争论。**这是贡献所在**，不是「验证了理论」。

### 5.3 可直接套用的句式
- 悖论钩子：「按理说，X 应当导致 Y；然而在实际中，我们看到的是非 Y。」
- 客体界定：「本文把 X 界定为……，其边界由三个条件共同确定：……」
- 符码：「在语料中，X 与 Y 稳定地分属两个对立的意义簇：前者关联……，后者关联……」
- 过程：「这一过程可划分为三个阶段，每个阶段的转折点是……」
- 证据：「下表把同一主题下的正例与反例并置，可以看到……」
- 回响：「我提出『X』这一概念，用以指称……；它与既有的 Y 概念的区别在于……」
- 局限（强纲领特有）：「本文的材料只覆盖……，因此不能推断……」

### 5.4 写作的三个致命伤
1. **只有深描，没有机制**：读者读完知道了很多细节，但说不出「所以呢」。
2. **概念先行**：先有「我要用布迪厄」，再去找材料；结果是材料被削足适履。
3. **贡献写成「丰富了相关研究」**：这是最容易被拒的一句话。贡献必须是「改变了哪场争论」或「提供了一个可被别人用的概念」。

### 5.5 投稿前自查（10 条）
1. 一句话问题能不能在 30 字内说完？
2. 分析单位的边界写清了吗？
3. 有没有一个明确的反例检验？
4. 关键概念有没有给出原作者定义与出处？
5. 方法节有没有写「怎么读」，而不只是「怎么收集」？
6. 有没有把相关说成因果？
7. 结论有没有超出材料的推断？
8. 所有引用是否真实存在（逐条核）？
9. 有没有一段话是「只有你能写、别人写不出」的？
10. 审稿人最可能问的三个问题，你在文中回答了吗？

## §6 评估论文质量

**先判路线，再用对应量表**（详见 `review-rubric.md`）。这里只给三条通用判据：

1. **它有没有一个可回收的主张？** 读完能不能用一句话说出「作者认为什么机制在起作用」。
2. **它的证据能不能支撑那个主张？** 特别注意：材料是「例证」还是「证据」——例证只能说明可能，证据要能排除替代解释。
3. **它的概念有没有被用到位？** 借来的概念是否承担了分析工作，还是只做了装饰。

**评语模板（三段）**
```
## 判断
（路线 + 一句话总评 + 分数）

## 最强的部分
（具体到段落/做法，说明为什么强）

## 最弱的三处
（每处：问题 → 为什么是问题 → 怎么改）

## 如果要救这篇论文
（按优先级给 3 步，标注哪一步是必须的）
```

## §7 精读导读

**结构**
1. **这本书在干什么活**（一句话，不超过 30 字）。
2. **它的靶子是谁**（没有靶子的理论书不值得读）。
3. **核心装置**（3–6 个概念，每个一句定义 + 出处）。
4. **最值得读的三章**（给页码，说明为什么）。
5. **可以跳过的部分**（诚实说）。
6. **读完之后你应该能回答的三个问题**。
7. **它的软肋**（至少一条，附出处）。

**禁止**：复述目录；把作者的话改成「作者认为……」的和稀泥式转述；不标页码。
