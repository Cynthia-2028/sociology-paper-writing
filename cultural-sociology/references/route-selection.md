# 三路线选择：差异、话术与判据

> 本文件解决一件事：**当用户提出「解答专业问题 / 学习知识点 / 探讨选题 / 撰写论文」时，先问路线，并把三条路线的差异讲清楚。**
> 用法：先读 §1 的表（对外解释用），再按 §3 的脚本提问，最后按 §4 处理回答。

---

## 1. 一页对照表（对外解释可直接用这张表）

| 维度 | 布迪厄路线 | 强纲领路线 | 计算测量路线 |
|---|---|---|---|
| **一句话** | 文化是被争夺、可兑换的权力资源 | 文化是自足的意义结构，有自身语法与因果力 | 文化是可测量、可比较的意义分布 |
| **文化的地位** | 资本的一种形态；意义随位置而变 | 自变量；相对自主的符号系统 | 待测的潜变量；由语料中的模式推断 |
| **因果箭头** | 位置 → 惯习 → 实践 → 制度奖励 → 位置（循环再生产） | 符码/叙事 → 表演/创伤过程 → 制度后果 | 变量间关联、预测、随时间变化（慎谈因果） |
| **分析单位** | 场域中的位置、资本组合 | 文化客体（事件、仪式、文本、物）内部的符码与叙事 | 文档、词、主题、关系边 |
| **核心概念** | 惯习、场域、资本、象征暴力、区隔、边界 | 二元符码、叙事文类、文化创伤、公民领域、社会表演 | 意义结构、主题、语义维度、关系构型 |
| **典型方法** | 对应分析（MCA）、场域民族志、生活史访谈、边界访谈 | 厚描、档案与文本编码、过程追踪、比较案例 | 主题模型（LDA/STM）、词嵌入、网络与关联规则、监督分类 |
| **什么算好研究** | 揭示一个「看不见的再生产机制」，并说明它如何被误认 | 重构意义结构，并指认它如何介入具体过程 | 测量有效、稳健、可复制，且说明了推断边界 |
| **典型贡献语式** | 「我揭示了 X 如何通过 Y 完成再生产」 | 「我提出 X 这一概念，它重构了 Y 之争」 | 「我提供了一套测量 X 的方法，并验证了它」 |
| **最容易被攻击处** | 经济决定论、静态、忽略能动性 | 唯心主义、不可证伪、美国中心 | 去语境化、效度不足、把模式当意义 |
| **政治姿态** | 批判/揭露（去自然化） | 规范/修补（公民领域的内在批判） | 技术/描述（立场通常不写入论文） |
| **最难回答的问题** | 文化为什么变了？ | 什么会算作你错了？ | 你测的到底是意义还是词？ |

## 2. 五组根本分歧（解释「为什么不是一回事」时用）

### 分歧一：意义在哪里？
- **布迪厄**：意义在**关系**里——一个品味的意义由它在场域中的位置决定，不由它自身决定（Swartz PDF p.66、p.67）。
- **强纲领**：意义在**结构**里——符码与叙事的内部对立自身产生意义，可脱离社会位置分析（*Meanings* PDF p.26–27）。
- **计算测量**：意义在**分布**里——一个词的意义由它与哪些词共现决定（分布假设）；或在**关系构型**里（网络位置）。
> 这三句话可以互相翻译，但不能互相替代。**判断一份研究属于哪条路线，先问「它把意义放在哪里」。**

### 分歧二：文化是原因还是结果？
- **强纲领**：文化是解释项（自变量），且必须指名「谁在何时以何方式」被文化引导（*Meanings* PDF p.27）。
- **布迪厄**：文化既是被结构化的（结果），又是结构化的（原因）；单看一头都是误读（Swartz PDF p.103）。
- **计算测量**：通常只主张「关联/预测」，把因果留给专门设计；把相关说成因果是本路线最常见的越界（Grimmer 等对 FPCILV 的警告）。

### 分歧三：要不要「厚描」？
- **强纲领**：必须。厚描 + 把非象征关系「括出去」，先造出分析上自主的文化客体（*Meanings* PDF p.27）。
- **布迪厄**：要，但厚描的对象是**实践感**，不是文本的内部结构；关键是 reconstruct 位置与倾向的对应。
- **计算测量**：以「远读」换规模；解释学回归是最后一步，不是第一步（Mohr 等：先测、后读，但必须回读）。

### 分歧四：批判的位置在哪？
- **布迪厄**：批判是**揭露误认**——让被支配者看见自己如何共谋（象征暴力）。
- **强纲领**：批判是**内在的**——用公民领域自己的承诺衡量现实，因此是「公民修补」而非革命（这也是它被指为保守的地方）。
- **计算测量**：批判通常不在方法层，而在「选择测什么」这一层（谁的语言被当作语料、谁的沉默没被计入）。

### 分歧五：什么算「解释成功」？
| 路线 | 成功的标志 | 失败的标志 |
|---|---|---|
| 布迪厄 | 找到一个「位置—倾向—奖励」的闭环，且能说明它为何不被当事人察觉 | 只剩「阶层影响品味」的相关，没有机制 |
| 强纲领 | 重构出符码/叙事结构，并证明它在具体过程中起了作用 | 只有深描，没有机制；或机制不可反驳 |
| 计算测量 | 测量通过验证、结论对预处理与参数稳健、推断边界清楚 | 只报 top terms；K 随手定；把主题当符码 |

## 3. 提问脚本（必须执行，且只问一次）

### 3.1 触发条件
用户请求属于以下任一类型时，**先问路线，再动手**：
- 解答文化社会学的专业问题（「布迪厄的场域到底什么意思」「文化创伤理论怎么用」）
- 学习知识点（「带我学文化社会学」「解释一下象征暴力」）
- 探讨选题（「我想研究小镇做题家，从哪切入」）
- 撰写论文（「帮我写一篇文化社会学论文」「这个题目怎么设计」）

**不需要问**：纯科普（「文化社会学是研究什么的」）、文献查证（「这本书哪年出的」）、纯格式任务（「帮我把这段改成学术语体」）、用户已明确指定路线（「用强纲领帮我分析」）。

### 3.2 提问模板（照抄，改成自然语气）

> 这个问题在文化社会学里有三条做法差别很大的路线，选哪条会直接决定你用什么材料、怎么论证、论文长什么样。先看一下差别：
>
> | | 布迪厄路线 | 强纲领路线 | 计算测量路线 |
> |---|---|---|---|
> | 关心什么 | 谁得到了什么、为什么能代代相传 | 这件事为什么被理解成这样 | 这种理解有多广、怎么变 |
> | 材料 | 访谈、履历、场域观察、调查数据 | 文本、事件、仪式、档案 | 大规模语料、平台数据 |
> | 贡献 | 揭穿一个看不见的机制 | 造一个新概念 | 给一套可复用的测量 |
>
> 你更想走哪条？如果拿不准，告诉我你手上的材料是什么、你想让论文的贡献落在哪里，我帮你定。

### 3.3 三条路线各配一句「自测题」（解释时逐条给）
- **布迪厄**：你是不是想知道「为什么同样的努力，结果不一样」，并且怀疑答案藏在「被当成理所当然的差异」里？
- **强纲领**：你是不是想知道「这件事为什么会被讲成这个故事」，而不是「谁在利用这个故事」？
- **计算测量**：你是不是已经有一批文本/数据，想知道「这种说法在多大范围内、以什么方式变化」？

### 3.4 三种特殊回答的处理
| 用户回答 | 处理 |
|---|---|
| 「我不确定 / 你帮我选」 | 用 §3.5 的默认规则选一条，**明确说明为什么**，并给「如果换成另一条，会长成什么样」一句话 |
| 「三条都要 / 能不能结合」 | 不说「当然可以」。按 §5 给**合法的组合**（主路线 + 辅助路线），并说明哪一步用哪条、哪一步不能混 |
| 「我选 X，但我的材料更像 Y」 | 指出材料与路线的错配，给两个选项：换材料，或换路线。**错配是审稿最常见的致命伤** |

### 3.5 默认规则（用户不愿选时）
- 有**大规模文本/平台数据** → 计算测量为主，强纲领做解释学回归（这是最容易做砸也最容易出彩的组合）。
- 有**访谈/田野/履历**且关心不平等 → 布迪厄为主。
- 有**单一事件/文本/仪式**且关心「意义如何被组织」 → 强纲领为主。
- 关心**概念本身**（「什么是惯习」）→ 按概念归属直接答，不必问路线；但要说明它属于哪条路线、在另一条路线里会被怎么批评。

## 4. 三条路线的「互相批评」一句话版（用于回答「它们能不能兼容」）

- **强纲领看布迪厄**：文化被化约为位置的反映，符号结构失去了自主性；布迪厄无法从文化内部生出批判与变迁（Gartman 的转述与反驳，见 `debates.md`）。
- **布迪厄看强纲领**：把文化当成自主的符号系统，等于假装权力不存在；「公民领域」的符码表本身是特定历史的产物。
- **计算测量看两者**：两边的关键概念都无法测量、无法复制；「深描」出的机制不可比较，「场域」的边界不可操作化。
- **两者看计算测量**：词频不等于意义，主题不等于符码，模型找到的模式不等于文化机制（`computational-route.md` §9、§10）。

> 回答「能不能结合」时的正确姿势：**结合发生在「分工」上，不发生在「本体论」上**。你可以用主题模型找话语丛、再用强纲领的符码分析读它，但你不能同时主张「文化是自足结构」和「文化只是位置的反映」。

## 5. 合法组合与非法拼贴

### 5.1 四种合法组合
| 组合 | 做法 | 已有范例 |
|---|---|---|
| **计算 + 强纲领** | 主题模型/嵌入找话语丛 → 厚描读符码 → 用符码结构解释时间序列 | Mohr & Rawlings 的「形式模型 × 诠释学」议程；`strong-books-3.md` 手册第 9 章 |
| **计算 + 布迪厄** | 用文本/行为数据构造品味空间 → 对应分析定位 → 检验资本与位置的对应 | Bennett 等的 MCA 传统在文本数据上的延伸；`bourdieu-route.md` §4.2 |
| **布迪厄 + 强纲领** | 用场域确定「谁有资格说话」→ 用符码分析他们说了什么 | 文化生产场域研究；争议性公共事件研究 |
| **三条并用（ rare）** | 只在「测量—结构—位置」三层都要交代的博士论文级别项目里成立 | 需要三套效度标准，成本极高 |

### 5.2 两种非法拼贴（要明确劝阻）
1. **「用布迪厄的概念 + 强纲领的本体论」**：一边说文化是位置的反映，一边说符码自主演化——两句话不能同时为真。
2. **「用计算的方法 + 强纲领的结论」**：用 LDA 得到 20 个主题，直接称其为「公民领域的二元符码」——主题不是符码（三条理由见 `computational-route.md` §9）。

## 6. 按任务类型的默认路线（用于「快速给建议」）

| 任务 | 默认路线 | 理由 |
|---|---|---|
| 科普「文化社会学是什么」 | 不选路线，三条并列讲 | 这是领域介绍，不是研究 |
| 解读一个社会现象（如「内卷」「小镇做题家」） | 强纲领（意义）或布迪厄（不平等） | 看用户关心「为什么这么讲」还是「谁受益」 |
| 解答专业概念问题 | 按概念归属 | 惯习/场域/资本→布迪厄；符码/创伤/表演→强纲领；主题/嵌入→计算 |
| 学习知识点（系统学） | 先布迪厄打底，再强纲领，最后计算 | 布迪厄给「不平等」的问题意识，强纲领给「意义」的分析工具，计算给「规模」 |
| 探讨选题 | 先问路线，再按路线的「缺口清单」生成 | 三条路线的缺口不同（见各路线文件 §11 与 `task-playbooks.md`） |
| 撰写论文 | 必须问路线 | 三条路线的论文骨架完全不同（COPE-R vs 场域分析 vs 测量论文） |
| 评估论文质量 | 先判路线，再用对应量表 | 用强纲领的标准评计算论文是范畴错误（见 `review-rubric.md`） |

## 7. 中文文献里的分类冲突（回答「学界怎么分」时必须知道）

三篇常被引用的中文文献给了三套不同的地图，**它们互相冲突，不要合并成一套**：

| 议题 | 周怡（强/弱范式） | 肖文明（审 Swidler 的理论预设） | 王蹊（三条路径） |
|---|---|---|---|
| 分类轴 | 强范式 / 弱范式（亚历山大判据） | 不分类，直接审预设 | 价值观 / 工具箱 / 认知 |
| Swidler 的位置 | 弱范式 | 主要批判对象 | 第二条路径的转折点 |
| 布迪厄的位置 | 弱范式（文化是因变量） | 隐含资源（实践意识） | 认知路径的资源之一 |
| 强纲领的位置 | 强范式的核心 | 主要理论资源 | 被搁置（注 1 说「留待讨论」） |
| 缺口 | 判据本身被批评为修辞装置 | 缺经验落点 | 「三路径」漏掉符码/强范式这一整支 |

**正确说法**：中文文献实际给出的是**四条**路径（价值、工具箱、认知、符码/强纲领），「三路径」是教学简化。详见 `debates.md` §4。
