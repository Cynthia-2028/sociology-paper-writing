# 社会学论文写作 · Sociology Paper Writing

一个面向社会学实证论文写作的**Agent Skill**：手把手指导从选题到结论，以及期刊选择与投稿适配。

> A section-by-section, hand-holding skill for writing sociology / social-science empirical papers — from research question to title, abstract, introduction, literature review, research design, empirical analysis, conclusion & discussion, plus journal fit and submission.

## 它解决什么
本技能按论文环节拆成可单独调用的11个模块，每个模块都给出：**步骤 / 可复制模板 / 反模式 / 自检清单**。

## 核心方法
- **洋八股八部分**：问题 → 文献 → 假设 → 测量 → 数据 → 方法 → 分析 → 结论。
- **证明性写作**：论点 + 论据，基于事实。
- **文献综述=论证不是报告**：map + argument。
- **写作可习得、靠重写**：先粗糙草稿，多稿修订。
- **读者能量模型** + **Strunk 18条**：省句法能量、主动/肯定/具体/删冗余。
- **先定期刊**：没有通用好论文，好论文是"为某本期刊而写"。

## 使用
把本仓库放入Agent的技能目录即可，或用`SKILL.md`的description触发。调用示例："帮写摘要""文献综述怎么写""从选题到成稿""投哪本刊"。
